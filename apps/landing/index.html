Kyalulu
手元で使うキャラクターAI

あの子は、ちゃんと覚えている。

Kyaluluは、ローカルファーストのオープンソースCharacter AI。キャラクター・会話・記憶をPCに保存し、ローカルLLMで物語の続きを楽しめます。外部APIも任意で接続でき、その場合は会話に必要なデータを提供元へ送信します。

GitHubで試す（アルファ）npmで導入する（ベータ） クラウド版の通知を受け取る

ローカル版は無料のオープンソース（AGPL-3.0）。ローカルでAIを動かせない方向けに、クラウド版を準備中です。

ローカル版

自分のPCで動かす、いちばん手元に近い使い方。

  • ローカルのモデルを使えば、会話・キャラ・記憶は端末の中で完結
  • ローカルLLMをPC上で実行（LE・LM Studio・Ollamaなどに接続）
  • 外部APIも任意で接続可能。送信データの扱いは提供元の規約によります
  • 無料のオープンソース

動かすには、AIを動かせる程度の性能のPCが必要です。

クラウド版 準備中

PCがなくても、スマホだけですぐに始められる。

  • ローカルでAIを動かせない方も、クラウドのモデルで会話
  • 会話データは任意でサーバーに同期（いつでも切れます）
  • 安全にサービスを運営するための、最低限の基準を設ける予定

料金・利用条件は公開時に案内します。扱えるのは全年齢向け（SFW）の内容のみです。運用の準備が整いしだい公開します。

✦ How it differs

ほかのRPツールと、
どこが違う？

一般的な傾向との比較です。サービスにより異なります。

クラウド型RPサービスローカル型ツールKyalulu
データの置き場所サービスのサーバー自分の端末ローカル版は端末内。クラウド版は任意で同期
長期記憶サービスにより異なる拡張や設定で補うMemory Labで記憶を確認・編集
スマホで使う手軽に使える設定が必要なことが多いPWA。PC連携またはクラウド版
既存キャラの持ち込み貼り付けなど手作業が中心形式によるCCv2/v3・SillyTavern・貼り付け移行に対応
はじめやすさ登録してすぐ導入に手間がかかるアルファ版は導入に手順が必要。クラウド版を準備中

記載の名称は各権利者のものです。Kyaluluは、各ツール・サービスの公式製品ではありません。

✦ Get started アルファ

3ステップで、会いにいく。

アルファ版は、GitHubから導入します。手順は少し開発者寄りです。扱いやすい形での配布は準備中です。

Node.js 22以上でnpmからローカル版（ベータ）を入れるか、ブラウザから全年齢向けのクラウド版へ。配布と運用の確認が終わりしだい利用できます。

  1. リポジトリを入手する

    npmで導入する（ベータ）

    GitHubからコードを取得し、READMEのクイックスタートに沿ってセットアップします。
    git clone https://github.com/ELRdn/Kyalulu.git

    Windows 11 x64／macOS Apple SiliconでNode.js 22以上を用意し、npx kyaluluで起動。配布物は検証後に公開します。

  2. ローカルエンジンを入れる

    AIを動かすローカルエンジン（Kyalulu Local Engine・LM Studio・Ollama）に接続して、使うモデルを選びます。外部APIも任意で設定できます。モデルの接続ガイドへ。

  3. キャラと会う

    用意されたキャラクターと話すか、持っているキャラクターを読み込んで、続きから。スマホから使うならPWA導入ガイドへ。

よくある質問

?
ローカル版は、データが外に出ませんか？

ローカル版では、会話・キャラクター・記憶をお使いのPCに保存します。ローカルLLMだけで会話する場合、生成のために会話を外部AI提供元へ送信しません。外部APIを設定すると、会話に必要なデータをその提供元へ送信し、提供元のデータ利用・保存規約が適用されます。外部Hubの検索・取り込みや、スマホからPCへの接続には通信が発生します。

クラウド版では、データはどう扱われますか？

クラウド版は準備中です。保存先・外部AI提供元への送信範囲・同期・利用条件は、公開時の利用規約とプライバシーポリシーで確認してください。

ローカル版にも、内容の制限はありますか？

ローカル版は、お使いの端末の中で動作します。ローカルのモデルを使う限り、RPの内容が外部のサーバーに送られることはありません（外部のAPIを自分で設定した場合は、そのAPIの規約に従います）。どのモデルを使うか、どんな物語を作るかは、利用者の判断になります。

無料で使えますか？

ローカル版は、AGPL-3.0のオープンソースとして無料で使えます。外部APIの利用料は各提供元の条件によります。クラウド版の料金・利用条件は公開時に案内します。

どんなPCが必要ですか？

動かすモデルによります。軽いモデルなら一般的なゲーミングPC程度、大きいモデルほど高い性能が必要です。動かせるか不安な方は、クラウド版をお待ちください。

いま、すぐに使えますか？

アルファ版を、GitHubで公開しています。導入には、READMEに沿ったセットアップが必要です。スマホのPWAは、現在はPC上のKyaluluに接続して使います。扱いやすい配布は準備中です。
