# 共通エラー案内の日英表示

対象は既存の `friendlyError` / `friendlyMessage`。呼出し元をすべて検索し、
新しい画面別wrapperは作らず既存の変換処理へ英語を追加する。

- ブラウザでは既存の言語設定を読み、SSRでは既存の日本語を維持。引数による言語指定も可能。
- 既存の接続/認証/利用条件/モデル/残高/運営予算/料金確認/転送/競合エラーと操作ラベルを英語化。
  エラーの分類順、リンク先、モデルID、コマンド、再試行の実行方法は変更しない。
- 料金を確認できない生成と提供元の制限による失敗は0消費、入力料金不足と運営予算による停止は
  別の案内として維持する。期限切れの転送を自動再実行する機能は加えていない。
- 未知の機械コードは既存同様に一般案内へ変換する。未知の自然文や提供元の生エラー、
  画面側で足している日本語の前置き、すでに状態へ保存された説明の言語切替は対象外。
  未接続機能の有効化やサーバーの認可条件を変更したものではない。
