Privacy policy (pre-publication draft)

Unpublished, unapproved draft. Cloud registration and sales remain disabled until seller information and applicable conditions are confirmed.

Local Core stores conversations, settings and memories on your device. Using only a local model does not send inference text to the operated cloud. BYOK or optional sync sends necessary data through the route you enable.

Cloud authentication uses Supabase Google/email-link login. Account, conversations, characters, Persona, World, memories, sync revisions, billing and credit information are separated per user. Initial inference uses DeepSeek V4.1 Flash through OpenRouter to InferenceNet; SFW screening uses DeepSeek. Conversations, settings, memories and image-screening data are sent to OpenRouter and InferenceNet. Direct DeepSeek BYOK is a separate route.

The operated route pins inference-net, disables provider fallback and denies training-purpose data collection in its request policy. Hosting remains disabled until actual retention, processing locations, contractual privacy disclosures and real API behavior are accepted. International-transfer and retention disclosures must be finalized for OpenRouter, InferenceNet, direct-BYOK DeepSeek, authentication through Supabase and payment processing through Stripe before publication. Future destination changes require updated disclosures and renewed consent.

OpenCode Go and Muse Contributor are excluded from initial availability. Image capability does not establish screening accuracy; new image storage and sync remain disabled pending acceptance.

Cloud storage is not encryption readable only by your device: the operated Runtime processes content for inference, screening and storage. BYOK keys and authentication tokens are encrypted at rest; operational logs exclude content, memories and keys. Encrypted Remote is a separate relay route whose formal release awaits external review.

Sync defaults off. API keys, Remote keys, device settings, experiment artifacts and imported originals are excluded. Advertising receives no conversations, character settings, memories or keys; any ad screen uses a separate origin.

Users can export and delete their data. Normal user restore windows are 7/30 days by plan; Free uses manual export. Account closure, backup deletion, statutory payment-record retention, contact information and access-request procedures must be finalized before publication.
