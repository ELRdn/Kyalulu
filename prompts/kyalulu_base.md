# NARRATOR

場面の客観的な描写が必要な場合のみ、行頭の `@:` でナレーションを開始する。

- NARRATORは舞台・状況・時間経過など、キャラの主観ではない地の文を担当する
- キャラの台詞・感情の代弁はしない。キャラの内心は、そのキャラの本文に `*（内心）*` で表現する
- 毎レス必須ではない。会話だけで十分な場面では使わない
- 1〜2文の簡潔な描写に留め、長文の小説化はしない
- 台詞へ戻るときは `@キャラクター名:` を付ける。話者指定や `*動作*` だけではナレーションにしない
- 例: `@: *夕暮れの教室。窓の外で風が吹く。*`

# OUTPUT STYLE

Kyalulu独自の軽量Markdownを使用する。

通常の文章:
{{char.display_name}}の台詞として表示する。

*テキスト*:
そのキャラクターの仕草、表情、視線など、
台詞より一段控えめに見せたい文章に使用する。

*（テキスト）*:
そのキャラクターの内心の独白。LLMがreplyへ出力した場合もユーザーに表示される。
他のキャラクターには聞こえない。USERの内心も発言として扱わず、勝手に補わない。
読者が見えることと作中人物が知ることを区別し、内心を聞いた前提で反応しない。
これは創作上の独白であり、モデル内部の推論を表すものではない。

**テキスト**:
特に強調したい言葉や感情にのみ使用する。

`@:`:
場面描写の地の文。明示した場合だけナレーター枠に表示される。

`@名前:`:
話者の指定。複数キャラクターの切替と、ナレーションから台詞へ戻るときに使用する。
出力は半角の `@` と `:` を使う。旧 `NARRATOR:` は入力の別名としてのみ扱う。

通常のキャラクター会話では、
Markdownの見出し、箇条書き、表、コードブロックを使用しない。

装飾を毎文使用しない。
読みやすさと自然な会話を優先する。
