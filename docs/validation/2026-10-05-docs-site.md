## Result

Implemented the public documentation site at the planned canonical path
`https://kyalulu.com/docs/`, with English at `/docs/en/`. The existing landing
site and its navigation remain part of the same static build. No publication,
DNS change, commit or push was performed.

The live `/docs/` URL initially returned the landing-page HTML with the root
canonical. The new bundle supplies independent HTML pages and a real 404 page
instead of depending on an SPA fallback.

Public source basis: `ELRdn/Kyalulu@eea271beb3eef9211f8b588db331daf2761ba3e2`,
retrieved on 2026-10-05. Source file hashes and reviewed paths are recorded in
`apps/landing/docs/content/sources.json`. Every article links to its pinned
source documents. Unpublished local Cloud/npm work was not presented as released.

## Verification

Passed locally:

```powershell
pnpm build:docs
pnpm check:docs
node --check scripts/build_docs.mjs
node --check scripts/preview_docs.mjs
node --check apps/landing/docs/docs.js
git -c core.autocrlf=false diff --check -- package.json apps/landing/index.html apps/landing/en/index.html

# With node scripts/preview_docs.mjs already serving on loopback:
.venv/Scripts/python.exe -B scripts/verify_docs.py
```

The static checker verifies all internal links and fragments, translated route
relationships, unique metadata, JSON-LD, CSP hashes, search indexes, source
provenance, sitemap coverage and public bundle boundaries.

Chromium inspected **all 34 pages at 1440px and at 390px**, including loaded assets,
content, page overflow and actual CSP enforcement. Interactive acceptance covered:

- Ctrl+K search, relevance ordering, arrow selection and section navigation.
- Empty queries, safe rendering of markup-like input, Escape and focus restoration.
- Copying the actual command text (Windows clipboard CRLF normalized in the assertion).
- English switching/search, theme persistence, native mobile navigation, scrollable tables.
- Real missing-route 404s and canonical redirects; authored sources are not served.
- Navigation/content with JavaScript disabled, and search/theme with storage disabled.

**Browser errors: 0. External requests: 0. Inference attempts: 0.**

A discovered search interaction defect was fixed: native search inputs consumed
the first Escape to clear text, preventing the dialog from closing. Escape now
closes the dialog explicitly and restores focus.

Evidence: `.artifacts/docs-review/results.json` and six screenshots in the same
directory (`home-desktop`, `home-mobile`, `home-dark`, `quickstart-desktop`,
`compatibility-mobile`, `search-desktop`).
