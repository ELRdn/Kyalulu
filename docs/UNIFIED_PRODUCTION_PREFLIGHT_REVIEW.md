# 本番の読取専用照合：承認対象

統合前後のデータ保持を照合する準備。自動承認レビューが、本番DBの集計情報を
SSH経由でローカル保存する具体的な許可を確認できないとして取得を拒否した。
この文書は承認対象を明示するもの。2026-10-29に本範囲の明示許可を受け、
架空DB試験後に読取・集計の取得を実施した。集計本体はGit対象外へ保存し、
公開文書には含めない。本番反映や復旧の合格を示すものではない。

## 読み取る対象

- 既存Kyalulu Cloud VPSの現在稼働中のRuntimeコンテナ。
- 既存設定の本番 `control.db` と各tenantの `data.db` をSQLiteの `mode=ro` と
  `PRAGMA query_only=ON` で開く。CloudStoreの生成・migrationは呼び出さない。
- 各DBのintegrity check、テーブル件数、全行を検出対象とするテーブル単位の
  SHA-256、既存の本人限定・受付数・提供元・機能無効化・検証予算の設定値。
- アカウント数、残高台帳のremaining合計、operation数、計上原価合計、
  pending・hold・debt・reviewの件数または金額。

## 送信・保存範囲

- 本番サーバー内で行のハッシュを計算する。会話本文・記憶・個別row・owner ID・
  メール・認証session・鍵・環境変数全体・DBファイルを外へ出さない。
- 各tenantの識別子は `tenant-1` などに置き換える。認証用3テーブルは対象外。
- 上記の集計・DB検査結果・テーブル単位ハッシュだけを、既存のホスト鍵照合を
  維持したSSHで作業PCへ返し、このリポジトリのGit対象外フォルダー
  `.artifacts/unified-vps-preflight-20261029/` に保存する。
- 集計・ハッシュでも非公開の運用情報を含む。Git・公開PR・外部サービスへ
  保存しない。報告は確認結果と必要な集計だけにする。

## 実行範囲と制約

具体的な読取コードは同フォルダーの `snapshot.py`。架空DBを使った
`snapshot_selftest.py` で原本のbyte保持・rawデータ非出力・変更検出を確認する。
本番での実行は本範囲の明示許可後に限る。

サービス停止・再起動、設定変更、DNS変更、DB更新・移行・復元・削除、
データ/台帳/予算のリセット、実推論、決済、契約、メール送信は含まない。
複数DBをまたぐ完全に同時のsnapshotや、暗号化バックアップ/復旧の合格を
証明する処理でもない。切替前の停止・backup・復旧は別工程として扱う。
