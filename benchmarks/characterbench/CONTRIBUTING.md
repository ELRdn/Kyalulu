# Contributing

Run `python -m kcb selftest` and document any protocol/data changes. Add regression tests for failures, not only successful fixtures. Never compare a MOCK fixture with a real model or label a transport simulator as a model test.

Use original, non-personal scenario content. Do not add answers copied from another benchmark without reviewing its license and documenting provenance. Keep public development items separate from any independently constructed held-out evaluation. Prefer reviewable allowed answer ranges over stereotypes.

Do not tune questions, weights or judge prompts to make a preferred model win. Publish exclusions, test revisions, generation failures, missing usage and unjudged samples. Preserve raw observable evidence, but do not store private API credentials or hidden reasoning content. Treat candidate/judge output as untrusted text, never executable code.

This package starts under MIT for its newly generated code and corpus. It is not a license change to the Kyalulu application or another repository.
