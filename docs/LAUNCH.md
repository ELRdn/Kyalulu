# 無料OSS＋任意クラウドの初回公開

策定: 2026-10-03 / 状態更新: 2026-10-05。製品の中心はキャラクターの人格・記憶・世界・関係性。
「キャラクターと、その記憶や世界を持ち続けられるCharacter AI」。

無料Coreはキャラ管理、会話、Memory Lab、Persona/World/関係性の保存、
入出力、ローカルモデル接続・BYOKを提供する。クラウド契約・アカウント・
K-Creditsを必須にしない。モデル提供元のBYOK料金は利用者負担。

## 現在の個人テスト

`https://cloud.kyalulu.com` に独立Runtimeを配置し、Supabase/Google/HTTPS設定と
本人ログインは完了。本人1アカウント限定でDeepSeek V4.1 Flashの推論経路を有効化し、
500 K-Creditsを単回付与済み。サブスク・追加購入・広告・画像保存/同期は停止。
一般公開・販売の受け入れ完了は意味しない。

表示名・保存キャラ・ピン留めのアカウント保存、クラウドのキャラ表示修正、
zeta参考のプロット作成UIを反映済み。一時下書きはブラウザータブ内、確定保存は
アカウントのサーバーDB。実ログインでの作成/保存と実端末間の確認は残る。
累計API実費上限は$0.10。前回分と不確定予約49,548,721ナノドルを引き継ぎ、
残り50,451,279ナノドルを超える予約はしない。検証台帳と個人テストから並列送信しない。
日英20ターン×3の評価履歴は存在するが、本番経路・人手品質・運用受け入れは別。
最新のリリース・証跡・次の作業は [引き継ぎ](HANDOFF.md) を参照。

## 公開範囲と状態

- npmローカルベータ：Node 22+、Windows 11 x64 / macOS Apple Silicon。
  起動・停止・診断・更新・バックアップ・復元・前版選択のCLI。
  ハッシュ検証する固定Python/依存/ビルド済みUI。実機と配布物の受け入れ後に公開。
- ブラウザ/PWAクラウド：PC停止中も独立稼働する別Runtime。
  Supabase Google/メールリンク認証、同一オリジン、利用者単位の保存・タスク分離。
  生成前後・保存・同期をSFW検査。本人限定推論は有効。一般受付/販売は受け入れ後に別途有効化。
- 運営経路（2026-10-04確定）：Kyalulu Cloud Standard → OpenRouter → InferenceNet。
  会話・構造化/大きな文脈・SFW検査をすべてDeepSeek V4.1 Flashへ固定。
  初月からOpenRouterを使い、Go契約や安定後の移行を前提にしない。
  JSON/State検証を維持し、拒否・障害・予算超過で別モデル/提供元へ自動転送しない。
  DeepSeekは非思考を要求。Muse Contributorは初回提供に含めない。
  `inference-net`を固定し、fallback/提供元の学習目的のデータ収集を拒否する設定。
  新環境では実API/保持条件/費用の確認まで `KYALULU_OPENROUTER_APPROVED=0`。
  既存VPSは本人限定で承認済み。公開用受け入れや別環境へ自動的に転用しない。
  今後の送信先変更は説明更新と再同意を伴う。既存のGo同意は転用しない。
- 最初の10人の受付後に72時間観測し、条件が整ってから100人へ拡張する。
  観測完了は最初の10人を受け入れる前提条件にはしない。
- Hosted BYOKはDeepSeekのみ、接続先の自由入力なし。キーはサーバー側暗号化保管。
- Remoteはクラウド保存・外部推論とは別の暗号化中継。外部レビューまで開発候補。

## 将来の商用プラン（現在は販売停止）

以下は販売開始時の仕様。個人テストでは自動試用付与・月次付与・Checkoutを有効化しない。

| | Free | Plus | Pro |
|---|---:|---:|---:|
| 月額 | $0 | $5 | $10 |
| ローカル/BYOK | 無料 | 無料 | 無料 |
| 運営API付与 | 初回1,000 | 月12,500 | 月25,000 |
| 保存容量 | 25MB | 250MB | 1GB |
| 選択/全同期 | 対応 | 対応 | 対応 |
| 過去版復元 | 手動エクスポート | 7日 | 30日 |
| キュー | 通常 | 通常 | 優先（通常の処理機会あり） |
| 追加購入 | 対応 | 対応 | 対応 |

10,000整数K-Credits＝$1。追加は$5＝50,000/$10＝100,000。
月次付与は月額の25%相当であり原価同額提供ではない。
API原価（入力/出力/安全検査/再試行）×6を合算して最後に切り上げる。
OpenRouterの `usage.cost` を実請求原価として保持。掲載単価上限は予約にだけ使う。
実請求が欠けた失敗は利用者0消費とし、不確定原価を運営予算へ含める。
成功最低1、失敗0。送信前にキャッシュ未命中・最大3試行の上限を確認して予約、完了後精算。
不明使用量は保守的な予約費用を運営側へ計上。BYOK/CRUD/同期/保存/輸出は利用者0。
月次付与は期間末、購入は180日、初回/広告は30日。近い期限から消費、譲渡/換金不可。

全体無料枠は本人確認済みアカウントに単回、原資を確保した範囲で付与。
原価枠は税/手数料控除後売上の20%。追加持ち出しの上限は月3,000円。
失敗・予約・未確定費用も含む。換算レートは運営で実勢と照合する。
返金/チャージバックでは関連残高・原資を無効化し、必要ならアカウントを停止する。
解約/容量超過で自動削除しない。閲覧・削除・エクスポートを維持し追加保存を停止する。

## 同期と復元

初期値オフ。選択した会話と関連キャラ/Persona/World/記憶、または全同期。
APIキー、Remote鍵、端末設定、実験、原本ファイルは対象外。
版番号＋冪等キーで409競合、勝手に上書きしない。クラウド版採用時は
ローカルCoreを別コピーへ退避できる。クラウドの編集/生成も版を進める。
ローカル連携は暗号化した分割転送を使用。検査済みの全ページが揃うまで
本体を更新せず、版番号と内容ハッシュを確認して一括反映する。
16MB超の転送・選択復元は自動検証済み。250MB/1GBでの時間・ディスク・メモリ上限は
実運用前に測定が必要。検査対象の単一行は50KBまで。一括互換APIは16MBまで。
手動エクスポートは容量超過でも論理データのZIPをダウンロードできる。
DeepSeek-V4.1-Flashの画像入力は公式仕様で確認済み。
画像入力Adapter、既定無効のSFW検査、明示的な画像送信同意、暗号化分割転送を実装した。
同期画像は静止画1MBまで。実画像での判定精度と原価を確認するまで、
`KYALULU_IMAGES_APPROVED=0` にして新規画像保存/同期は閉じている。
この制限は公開前の必須解消項目。別提供元を必須とはしない。

クラウドはチャンク認証付き暗号化バックアップ。7/30日の保持容量を販売開始前に確保。
容量受付は既存の有料利用者と未完了Checkoutの予約を合算してDB内で直列化する。
Checkoutは30分で失効、予約は35分。決済反映時は契約期限＋復元保持日まで確保し、
解約/ダウングレードでも強い既存の容量約束を期限まで残す。既存バックアップが占める
実容量に加えて将来の全予約を評価するため保守的な受付になる。実ディスクは別途用意する。
独立保管先への退避・新環境への復元は `scripts/cloud_admin.py`。
災害バックアップには台帳・利用者DB・画像・保持中の過去版を含める。
別ディレクトリへの暗号化退避・復元は自動検証済み。2026-10-05にVPSの暗号化バックアップを
PCへ転送し、プロフィール更新時のバックアップは隔離環境へ復元して整合性を確認した。
継続的な独立保管先への退避と、別ホストでの災害復旧は未受け入れ。
同じVPS上の別ディレクトリだけでは災害対策を完了と扱わない。
更新前のCoreバックアップとRuntime前版選択で取り消しに備える。

## 有効化の順序

1. 両OSでNodeだけの配布物導入、会話・記憶・再起動・更新失敗・復元を確認。
2. クラウドの認証/分離/同期競合/削除/容量超過/復元とRelayへの負荷影響を確認。
3. 整数台帳、同時処理、失効、料金変更、Stripe重複/順序逆転/返金を確認。
4. 日英各20ターン×3反復、人格/記憶/JSON/SFW/速度/総原価を測定。
   Android実機IME/ロック/回線切替/再接続、24時間運転、別環境復元。
5. 最初の10人で10分以内の初回会話を目指し72時間観測、その後100人へ。

新規受付は `KYALULU_CLOUD_SIGNUP_LIMIT=10` を既定にし、DBトランザクション内で制限。
0で新規受付停止、既存の認証/閲覧/削除/エクスポートは維持する。100への変更は実観測後。
解約Portalは新規販売/生成の停止と独立して利用できる。
既知の請求が予約上限を超えた場合は失敗0クレジット、超過額は運営負債へ記録し、
照合が済むまで追加送信を停止する。管理CLIのbudgetで負債と件数を確認する。

公開前チェックは `python scripts/check_launch_readiness.py`。初期値は未受け入れでexit 2。
証拠の実環境区分・ソース指紋・内容ハッシュを照合する。モック/開発PC/旧ソースの成功を
実機・実モデル・24時間運用済みとして扱わない。承認フラグや外部サービス設定は変更しない。

GitHub公開 → LP公開 → Product Hunt/Reddit/X告知。npm公開、契約、デプロイ、投稿は
それぞれ明示的な実行工程。実装のテスト通過を公開・実機・運用受け入れの代わりにしない。

広告はアプリと別オリジン、会話/設定/記憶/キーを渡さない。AppLixirは候補であり、
適合・署名されたサーバー完了通知・一回限りチケット・重複防止・日次上限・
確保済み原資の検証が成立するまで準備中。ブラウザコールバックでは付与しない。
将来の広告収益は無料枠原資に含めない。サブスクを独立して先行できる。
