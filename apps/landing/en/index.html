✦ Your data

You choose
where it lives.

Pick the mode that fits how you play. Each handles your data differently.

Local version

Runs on your own PC. The closest you can get to keeping everything yours.

  • With a local model, conversations, characters, and memories stay on your device
  • AI models run on your PC too (connect LM Studio, Ollama and more)
  • Free and open source

Requires a PC powerful enough to run AI models.

Cloud version Coming soon

No PC needed. Start right away from your phone.

  • Chat with cloud models even if you can't run AI locally
  • Conversations can optionally sync to a server (you can turn it off anytime)
  • A minimum set of safety standards is planned to keep the service safe to operate

Planned pricing: Free $0 / Plus $5 per month / Pro $10 per month. Cloud content is limited to all-ages (SFW). It opens once operations are ready.

✦ Get started Alpha

Three steps to meet them.

The alpha is installed from GitHub, and the steps lean toward developers. A friendlier distribution is in preparation.

Install the local beta with npm (Node.js 22+), or start in the browser with the all-ages cloud version. Available once distribution and service checks are complete.

  1. Get the repository

    Install with npm (beta)

    Fetch the code from GitHub and follow the README's quick start.
    git clone https://github.com/ELRdn/Kyalulu.git

    On Windows 11 x64 or macOS Apple Silicon with Node.js 22+, run npx kyalulu. Packages are published after verification.

  2. Install the local engine

    Connect a local engine that runs the AI (Kyalulu Local Engine, LM Studio or Ollama), then choose a model.

  3. Meet your character

    Talk to a built-in character, or import your own and keep going. To use it from your phone, see the PWA setup guide (in Japanese).

FAQ

Does my data leave my device with the local version?

The local version runs on your own PC, and conversations, characters, and memories are stored on that device. With a local model, your conversations never leave it. When you use it from a phone, the connection between phone and PC is encrypted.

How is data handled in the cloud version?

Cloud conversations, settings and memories are stored in the Kyalulu cloud. Replies and safety checks are planned to use external AI model providers, configured to refuse provider data use for training. Syncing from the local version is optional, off by default, and can be stopped anytime. Synced data is automatically checked against all-ages standards. Details will be set out in the terms of service and privacy policy at launch.

Does the local version restrict content?

The local version runs inside your own device. As long as you use a local model, your roleplay is not sent to an external server (if you configure an external API yourself, that API's terms apply). Which model you use and which stories you write are your own decisions.

Is it free?

The local version is free, open-source software under AGPL-3.0. Using your own local model or your own API key costs nothing on the Kyalulu side (API usage is billed by each provider). The cloud version is planned at Free $0 / Plus $5 per month / Pro $10 per month, and sales begin only after billing and operational checks are complete.

What kind of PC do I need?

It depends on the model. Lighter models run on a typical gaming PC, and bigger models need more power. If you're unsure your PC can handle it, wait for the cloud version.

Can I use it right now?

An alpha is available on GitHub. Setup follows the README. The phone PWA currently connects to Kyalulu running on your PC. A friendlier distribution is in preparation.
